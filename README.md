# 电影重击打斗导演

独立 AI 视频提示词技能：强冲击、清楚的空间与动作因果、长短镜交替、有限旋转运镜、受击表演和持续物理损伤。

**Cinematic Impact Fight** turns a fight premise into a coherent cinematic AI-video prompt: readable choreography, force and inertia, motivated camera movement, performance, and persistent environmental damage.

不绑定特定人物、模型或项目；支持整段提示词，也可按要求输出分镜。默认无配乐，超级慢动作仅按用户要求启用。不是现实格斗教学。

## 使用

### 一键安装

```bash
npx skills add 20574720/cinematic-impact-fight --skill cinematic-impact-fight --global --copy --yes
```

将此文件夹复制到支持 SKILL.md 的工具的技能目录。Codex 可放在 `~/.codex/skills/cinematic-impact-fight/`。

### 提供什么信息

告诉助手：人物及力量差异、场景与可用物体、上一段结束状态、总时长、必须发生的动作、最终结果，以及是否需要指定慢镜头。已有参考图或批准的镜头方案时一并提供，技能会优先继承。

示例请求：

> 使用 $cinematic-impact-fight，写一段20秒的成年女主对抗重型机器人的电影打斗。场景为下层工业车间，开局双方已经坠落；要求清楚的反制与重量、一次旋转运镜，最后女主受伤昏迷。给我合并提示词，不要分镜图。

技能入口：[SKILL.md](SKILL.md)。[完整示例](references/example.md)仅展示写法，不是必选剧情。

## 风格与能力

| 维度 | 技能如何处理 |
|---|---|
| 功夫电影叙事 | 攻防有动机，反制接在动作空当，每组交锋改变双方优势 |
| 强冲击与速度 | 短促爆发、真实接触、重量和制动，避免匀速挥拳与互相等招 |
| 动态摄影 | 连续中全景交代动作，短镜强调逆转；环绕和滚转跟随力量，结束后恢复方位 |
| 机械与环境破坏 | 接触后局部形变、零件脱落、设备承力；破坏位置与伤损跨镜保留 |
| 人物表演 | 从目光、呼吸、下颌与手指压力呈现决心、疼痛、抵抗和力量耗尽 |
| 次级动态 | 头发、衣摆、皮带、灰尘与松动结构按不同质量和惯性响应 |
| 慢动作 | 按明确要求只放大指定重击，标清片内时长，随后恢复实时 |
| 电影质感与声音 | 彩色实拍观感、可读暗部、细颗粒；默认无配乐，保留材质音与环境声 |
| 参考图分工 | 设定图控制外观，分镜控制构图和动作，防止素描描边污染成片 |

## 输出约定

默认给出完整可复制的整段提示词，使用合计等于请求时长的连续时间窗。用户只要提示词时不额外画分镜；已有镜头方案时不因为加入微表情而改变机位。时长、人物、结局和台词以当前请求为准。

## 适用范围

适合近身格斗、科幻机械打斗、工业场景重击，以及动作视频生成后的节奏与连续性修改。可用于编写不同视频生成工具的自然语言提示词，不预设某个平台的参数或保证其执行精度。具体模型支持的时长、参考图和慢动作能力请以该平台为准。

## 来源与范围

根据作者与 AI 助手迭代确认的创作偏好独立整理：力量传递、快慢对比、旋转服务动作、环境破坏、表演因果与连续性。未打包参考图片、私人视频或其他技能的源文件。提示词不能保证视频生成模型逐项精确执行。
