# 完整提示词示例

以下为成人角色的虚构机械格斗示例，不是固定剧情模板。20秒、彩色16:9，主要动作实时，仅指定一次超慢镜头。成年女主与男性外观的重型机器人在废弃工业车间的下层交战，起始双方已经落到下层，女主在画面右侧、机器人在左；北侧是凹陷设备柜，地面有一根沉重钢条，南侧通道可见。保持人物身份、损伤和场景方位。无背景音乐，只有有来源的环境声和动作音效。

0—4秒：中全景连续跟拍，女主从跪姿撑起，在机器人靠近时抓起钢条，利用全身重心带动一次猛烈挥击。头发与衣摆落后于躯干加速，钢条有重量，手臂不独立像风车转动。她盯住对手，短促呼气；机器人来不及完全避开，击中前不提前飞走。

4—5秒：单次超慢极近特写，占片内1秒。钢条实际接触机器人侧脸外壳，外壳先凹陷再裂开，小型接插件弹出，破裂线路喷出短促火花，头部沿受力方向偏转，帽子脱离头顶向后飞。脸部身份保持，破坏集中于机械结构，不出现血肉喷溅。背景虚化，接触点清晰。此后立即恢复实时。

5—10秒：接回中景同一动作余势，机器人带着裂开的头壳后退半步，帽子落到左后方地面。核心亮度升高，关节声音更紧更硬；他趁女主回收钢条时逼近夺走距离优势，重物被压到地面，发出刮擦。双方扭打中撞上北侧柜角，柜门在接触点凹陷。摄影机沿双方外侧弧线移动，持续保留脚下位置和柜子作为方位参照，随后稳定。

10—15秒：机器人突然占据主动，将女主举离地面后抛开，摄影机随抛起方向短暂上仰，保留两人在同一空间；在她下降途中，机器人完成一次飞踢，明确接触躯干后才把她带向北侧设备柜。柜门被背部撞凹，螺栓与灰尘落下，她沿柜面滑到地面。短促镜头震动后立即恢复稳定，衣摆与断开的柜门仍有余震。动作不重复播放，身体不悬空等招。

15—18秒：女主面部与支撑手的近景。她先把目光重新聚向逼近的威胁，咬住下颌，试图用手掌和肘撑起上身；手掌滑移、肘部失去支撑，上身落回。一次吸气不完整，手指慢慢卸力，眼睑最后合上，仍有微弱呼吸。坚韧来自她还想继续行动，而非夸张怒吼。

18—20秒：切高位斜俯的机器人背后过肩，前景是头壳破损、没有帽子的机器人背肩，女主完整可见地躺在北侧设备柜前。保持最后两秒构图稳定，钢条、落帽、凹陷柜门与碎片位置延续，呼吸和设备余响渐弱。彩色实拍电影质感，柔和高光、可读暗部、细胶片颗粒，避免游戏渲染、素描描边、肢体穿模、橡胶金属与无来源爆炸。
