# 动作、镜头与表演的具体写法

## 速度与叙事

先写优势转移，再选择招式。开局可以争夺站位，中段让一方利用重物或地形夺回主动，反制改变战局，结尾兑现代价。不是必须使用该固定弧线，用户剧情优先。

“很暴力、很快、很有冲击感”不足以指导生成。改写为可观察的连续事件：钢条进入画面→与机械头壳实际相碰→外壳沿接触点裂开→帽子被惯性带离→头与上身沿受力方向偏转→挥击者需要收住重物→对手利用她回收时的空当反制。不要把同一个动作拆成一串慢慢执行的命令。

挑选少量主动作构成可读链条。翻摔、空中反制、撞墙等高复杂度事件需要留出发力、移动和落地时间；模型难以稳定完成时，先删重复连击，不删接触或用剪辑掩盖不可能的运动。

## 摄影张力

### 战场可以沿动作推进

为每组动作记录简短的起点→路径→终点：例如中央通道→被逼退绕过立柱→侧墙设备区。下一组从设备区继续，人物不必回中间。距离随接近、击退与包抄改变；相机换边后屏幕左右可以对调，但门窗、柱子和固定设备的世界位置不改变。前镜出画的角色在后镜出现，需要路径与经过时间说得通。

多人场面按参与人数选择可读规模。给每人稳定标识，例如深色外套A、浅色护甲B，而不是切镜后重分编号。说明当前主要威胁、另一人的并行动作和主角注意力的转移；包围圈随有人受阻或倒地出现缺口，主角可以利用缺口转移。避免同一位置挤入多个身体或所有人同步同招。交代镜头建立人数和入口，近景聚焦一组接触，再回较宽镜头更新其余人的位置。

镜头随战局选择新侧面、斜后方、俯角和低角。旋转与横移可以在连续镜头内完成视角交接，也可通过匹配动作切到新的机位。视角变化要带来信息：新威胁、退路、落点、破坏结果或表情，而不是重复同一动作。不要硬性要求每次打完都复原起始轴线。

### 一张360度全景图如何使用

1. 确认是真正等距柱状全景、立方体面，还是仅为宽幅照片；没有依据不宣称覆盖完整360度。真实全景可约定参考正前方为0度，其他方向按顺序标记；普通宽图的未见区域属于补全。
2. 挑出少量稳定地标建立布局，例如门在后侧、设备柜在右侧、柱列位于中部。光源也绑定世界方向，换角度后光在人物脸上的投影随之变化，不每镜重新打同样的正面光。
3. 输出普通透视电影构图，依据机位朝向选择全景对应区域；禁止鱼眼拉伸、球面接缝、重复门窗或把整张全景压进单镜背景。若需实际制作透视参考图，使用能识别投影的工具，并检查输出，不把简单裁切称为透视校正。
4. 全景只有一个采集视点。旋转参考较直接，摄影机平移、升降和绕到物体后面需要深度推断；可合理补全，但固定结构与尺度、透视和遮挡要相容。破坏后的新状态覆盖参考图原状，不能下一镜又长回完好的柜门。
5. 按用户目标平台的实际上传限制另行制作方向参考；不强制每次都生成多张图，也不把360度场景参考等同于必须360度旋转摄影机。

- 中全景：交代全身支撑、距离与落点；低位近景可以放大重物掠过，但避免遮住击中位置。
- 短镜：在动作仍持续时衔接同一方向和速度，前镜挥击不应在后镜重新蓄力一次。
- 旋转：说明绕谁、向哪边、转多少、转到哪里停止。角度按动作需要选择，不固定90度或360度。维持地平线或有意短暂倾斜后恢复，不持续旋转炫技。
- 重击：接触瞬间可有一次短促震动，随即恢复可读画面；震动、速度线、模糊不是冲击本身。
- 超慢特写：只在明确要求的单次接触点放大材质变化，脸部结构保持身份，机械碎裂集中在外壳与内部零件；切回实时后继承损伤和帽子去向。
- 情绪结尾：先给完整可读的脸部近景，再给高位过肩总览时，机器人背部只占前景一部分，不挡住倒地者。鸟瞰的垂直程度和肩部比例要兼容，不同时要求正垂直俯拍和完整平视背影。

## 表演

攻击者：眼睛确认目标，重心先有目的地组织，发力时呼气，完成后有制动和判断。不要每拳都夸张张嘴。

受击者：接触后局部张力改变，视线短失焦或呼吸被截断，重新找到对手；下一次行动带着受伤后的限制。坚韧可以是吸不满气仍重新撑住，或手指滑落后再次抓住，不等于免疫冲击。

力量耗尽：先试图用手掌撑起，肘部承不住，身体落回；目光仍想追踪威胁但迟缓，手指逐渐卸力，呼气变弱，眼睑最后合拢。时间有限时保留两三条明确通道，不把瞳孔、血丝、下巴、眉毛和泪水全部同时启动。昏迷与死亡是不同结局。

机器人狂暴：优先用关节负载声、动作更直接、制动变硬、原有核心增亮体现；不无故变身、换脸或生成新装甲。其动力变化仍需保持身体与接触的物理逻辑。

## 常见失败与修正

| 失败 | 修正 |
|---|---|
| 互相等待、节奏匀慢 | 减少准备动作，把反制接在对方回收或失衡的瞬间 |
| 快剪但看不懂 | 增加一个完整接触的中景，交代当前方向与落点；换边后重新建立关系 |
| 每次交锋后回到原位 | 继承真实终点，让下一组从新位置开始 |
| 围攻变成轮流排队 | 给外围人物并行任务、进攻路线与受阻原因 |
| 换角度背景变成另一个房间 | 用全景地标固定世界布局，区分转向与平移需要补全的信息 |
| 人物像木板飞走 | 局部接触先驱动躯干，四肢与衣料随后响应 |
| 满屏粒子没有重量 | 减少粒子，强调接触、形变、惯性和落地 |
| 损伤消失、帽子复原 | 逐镜继承结束状态，明确帽子和零件的落点 |
| 表情只有凶狠 | 加入受压、重新聚焦、克制疼痛与继续行动 |
| 后半段赶完昏迷 | 从重复打击中腾时间，保留失败挣扎和最后构图 |
